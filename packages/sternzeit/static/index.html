Where the Sun, the Moon and the stars actually are, for any moment and any place on Earth. A dependency-free TypeScript library of astronomical position math, ported from osgHimmel, for renderers that want a sky which matches the real one.

This page is a live inspector for the library: pick a time and a place, and every value it computes is listed below and drawn above. Each quantity comes in a precise variant, following Meeus' Astronomical Algorithms, and a cheaper approximate one, following Jensen et al.; both are shown side by side so the cost of the shortcut is visible. Drag the scene to rotate, scroll to zoom, and hover a row in the tables to highlight what it corresponds to. The scene is not to scale: sizes and distances are chosen for legibility, not physical proportion.

altitude above: a sky altitude angle above the local horizon (0-90°), not an observer height above ground, this library has no elevation parameter. Feeds atmosphericRefraction directly and viewDistanceWithinAtmosphere as y = sin(altitude), the vertical component of a view direction vector, since that's the form a renderer's ray would already be in.

Part of himmel, a family of small, independent, composable libraries for rendering the sky, each usable on its own:

  • sternzeit, astronomical position math (this one)
  • dunstkreis, WebGPU atmospheric scattering
  • gewoelk, clouds planned
  • sternenzelt, star rendering planned
  • nachtgestirn, moon rendering planned
